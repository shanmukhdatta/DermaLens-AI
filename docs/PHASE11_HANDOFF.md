# Phase 11 — Uncertainty, abstention and explainability

After Phase 10 has real, independent validation: freeze calibration and test datasets separately. Compare temperature scaling against uncalibrated probabilities and select abstention thresholds on the calibration set only. Measure selective risk/coverage and per-class detection, then evaluate those chosen parameters once on the held-out test set. No forced prediction for uncertain/OOD images. Do not use an arbitrary softmax cutoff as a medical clearance rule. Integrate Grad-CAM only for compatible real model layers, keep source image private, indicate this is a model-influence visualization and not lesion localization. Validate explanation stability. Ensure no staging/public diagnostic activation until qualified clinical and privacy review.
