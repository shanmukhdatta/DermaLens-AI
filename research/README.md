# Research snapshot

Original source: https://github.com/shanmukhdatta/Facial_Skin_Diesease at commit `506459419d4d0eb13e943958746222aea31dc3ac`.

`legacy/` preserves the MIT-licensed training, model, inference, data, evaluation and synthetic generation **source**, separate from the deployed FastAPI/Next.js system. `legacy/LICENSE` retains attribution. Do not import this research package into production or install its heavy optional dependencies in the web/API images. Run `legacy/scripts` only in an isolated research environment using authorized datasets; no weights or private images are bundled.

This is a reproducible code snapshot, **not proof of training runs, model accuracy, clinical validity, or serving readiness**. The model connection requires the [private checkpoint parity runbook](../docs/MODEL_ARTIFACT_PARITY_RUNBOOK.md). Research prompts and large datasets stay in the original project.
